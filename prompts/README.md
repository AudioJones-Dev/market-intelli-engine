# Prompt Registry

This directory will store versioned prompt contracts and prompt text for MIE. It is currently
empty; the prompt registry lands at Milestone 13.

Rules:

- No unversioned production prompts.
- Prompt changes require a version bump.
- Prompt behavior changes require tests.
- Recommendation-affecting prompt changes require ADR review.

Initial prompt contracts are defined in `docs/07-PROMPTS.md`.
